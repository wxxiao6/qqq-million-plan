# 雷达个人可投余量

登录后，存在有效定投计划的基金渠道显示「定投中」，并在公共可投额度旁独立增加「今日预计剩余」列，单元格只显示剩余金额与「已记录 · 待执行」两行信息，不使用卡片、展开按钮或明细弹窗。同表无匹配计划的基金显示「—」；访客及整表无匹配计划的渠道不显示个人列。

## 计算口径

- 今日使用北京时间。预计剩余 = 已核验的每日限额 − 今日已记录申购金额 − 今日待执行定投金额，金额使用 Decimal 计算并保留两位小数。
- 已记录金额包含待确认、已确认订单的实际扣款（含手续费）；不包含补录的初始持仓、过往未确认余额、失败或取消订单。
- 同一计划同一期已存在订单时，不再重复扣减计划金额；失败、取消订单释放该期额度。
- 计划按原始起始日及日、周、双周、月频率判断，未来计划和已导入日期不重复计入。
- 优先采用订单已有 T 日；无 T 日时沿用账本的工作日及 15 点规则。当前沿用周一至周五近似，尚未接入法定节假日、境外休市日历，因此明确显示为预估，不代表平台实时可购余额。
- 只有相同币种、额度依据链接、共用额度标识的份额或渠道合并扣减。多个账户不直接倍增基金限额，共用限额取已核验成员的较小值。
- 暂停申购单独提示；未核验、未披露数值上限、账户与渠道不匹配时，不显示推测的剩余额度。计划超过限额时剩余显示为 0，并使用提醒色，悬停提示超额金额。

## 数据与性能

个人数据只通过带当前用户 ID 的两条绑定查询获取，读取有效计划及最近相关订单；本地 SQLite、线上 D1 使用同一计算逻辑。进入雷达只读数据，不触发自动记账，不改变数据库。个人余量不计入公共额度汇总，避免共用额度重复相加。无需数据库迁移。

## 验证

单元测试覆盖频率、截止时点、失败取消、共用额度、账户隔离、币种隔离、金额精度和超额；集成测试验证用户隔离、只读查询、本地及 D1 适配结果一致。浏览器使用隔离数据库的演示计划验证独立列、两行信息及表格对齐。
