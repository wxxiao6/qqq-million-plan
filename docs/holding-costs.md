# 基金手续费与持有成本

## 1. 手续费计算规则

定投记账金额视为包含申购手续费的扣款总额。手续费按以下优先顺序确定：

1. **实际手续费**：录入实际手续费时，以该金额为准。
2. **费率**：没有实际手续费时，按配置费率使用外扣法计算。
3. **固定金额**：没有实际手续费且配置了固定费用时，按该金额计算。
4. **未配置**：手续费按 0 元计算。

按费率计算时：

```text
净申购金额 = 扣款金额 ÷（1 + 申购费率）
申购手续费 = 扣款金额 − 净申购金额
持仓成本 = 扣款金额 − 申购手续费
```

金额按元四舍五入至两位小数。例如，扣款 10 元、费率 0.15%，手续费为 0.01 元，持仓成本为 9.99 元。固定费用和实际手续费也按分取整；系统不允许手续费大于或等于扣款金额。

普通持仓由用户填写持有份额、持仓总成本和持仓成本单价中的至少两项，系统计算第三项；不会额外推算申购手续费。定投自动记账和估算份额不代表实际交易，具体费率和金额以销售渠道及交易确认单为准。

## 2. 持有成本

基金持有期间，管理费、托管费等运作费用通常从基金财产中计提，并已反映在公布的基金净值中；部分基金还可能计提销售服务费。具体费用和计提方式以基金合同、招募说明书为准。[中国投资者网：公募基金的盈利模式](https://www.investor.org.cn/xxzx/tjzl/tjnrgmjytx/bk/kj/jyxl_3370/202302/P020230222356358137396.pdf) · [开放式基金费用一览表](https://www.investor.org.cn/xxzx/tjzl/tjnrgmjytx/bk/kj/jyxl/202302/P020230216398414064714.pdf)

**结论：公开净值已反映这些费用，但不能仅凭净值准确拆算投资者个人实际承担的持有成本。** 按持仓和费率计算只能得到估算；再次从“持有份额 × 净值”中扣除估算管理费，还会重复扣减。因此，项目决定**不再计算和展示持有成本**，也不再从市值中额外扣除估算管理费。

项目保留买入成本、申购手续费和持有收益。当前定投持仓成本不包含申购手续费，因此展示的持有收益也未扣除该手续费；若按实际总投入计算收益，应将手续费和分红、赎回等现金流一并考虑。
