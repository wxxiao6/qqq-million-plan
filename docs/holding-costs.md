# 基金成本与费用口径

本文区分买入时直接支付的费用、基金运作期间从基金财产计提的费用，以及项目目前展示的持仓成本和收益。实际收费以基金合同、招募说明书、销售渠道规则及交易确认单为准。

## 买入成本与申购手续费

项目的普通持仓由用户录入持有份额、持仓总成本和持仓成本单价中的至少两项，系统计算第三项。录入金额以用户的实际数据为准，系统不额外推算普通持仓的申购手续费。

定投的记账金额视为包含手续费的扣款金额。项目支持按实际手续费、固定金额或费率计算；按费率时使用外扣法：

```text
净申购金额 = 扣款金额 ÷ (1 + 申购费率)
申购手续费 = 扣款金额 − 净申购金额
持仓成本 = 扣款金额 − 申购手续费
```

金额按元保留两位小数。例如扣款 10 元、费率 0.15%，手续费为 0.01 元，持仓成本为 9.99 元。实际交易费率、最低收费及四舍五入规则以渠道为准；自动记账及估算份额并非真实交易，需与平台确认记录核对。

待确认资金按扣款金额展示，确认后净申购金额计入持仓成本；失败和撤单记录不计入已确认成本。不同购买平台和多笔已确认记录分别保存，展示时合计。

## 管理费、托管费与净值

管理费、托管费等基金运作费用一般从基金财产中计提，并体现在公布的基金份额净值中，不是投资者账户另外扣除的申购手续费。基金类型和合同规则可能不同；C 类份额等还可能涉及销售服务费。参见[中国投资者网：公募基金的盈利模式](https://www.investor.org.cn/xxzx/tjzl/tjnrgmjytx/bk/kj/jyxl_3370/202302/P020230222356358137396.pdf)和[开放式基金费用一览表](https://www.investor.org.cn/xxzx/tjzl/tjnrgmjytx/bk/kj/jyxl/202302/P020230216398414064714.pdf)。

**结论：不能仅凭已经扣除费用的公开净值，精确反推出个人实际承担的管理费或全部持有费用。** 使用费率、持仓份额和净值可以得到估算，但精度取决于实际计提基数、每日持仓和费率、休市日及基金合同等信息；这不是实际账单。净值已经反映费用后，再从“份额 × 净值”中减去估算管理费，会重复扣减，不宜作为账户实际市值或收益。

## 项目中的市值与收益

```text
持仓市值 = 已确认份额 × 最新有效净值
持有收益 = 持仓市值 − 已确认持仓成本
```

项目目前的定投持仓成本不含申购手续费，因此持有收益也未扣除这部分手续费。如果要与实际总投入比较，应另将申购手续费纳入投入；有现金分红、赎回、转换等情况时，还须结合相应现金流。估值缺少净值时无法完整计算市值和收益。

项目不再估算或展示个人管理费，也不再计算从净值市值额外扣管理费的对账指标。申购手续费、买入成本及持有收益保留。
