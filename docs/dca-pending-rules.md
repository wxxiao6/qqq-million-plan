# 定投初始化与在途资产

## 录入约定

定投计划仅支持纳指基金。新增计划时，除基金和每期金额外的表单内容保存在当前浏览器本地，下次打开新增弹窗时恢复；编辑已有计划始终使用计划本身的数据。

用户新增定投计划后，按起始日和计划频率自动生成截至今天的记账记录。每期记账金额使用计划金额；工作台不发起真实交易。
最近三个净值日是行情存储范围，不是自动补录范围；最近三个已公布净值日完整是雷达数据前提；缺失属于数据异常，不能作为正常业务流程保存只有金额的自动补录。
之后的计划日自动记账；应用运行时定期检查，重新打开页面时补齐运行中错过的期次。暂停期间不补记，恢复后从恢复日继续。记录可在定投管理中修正金额或标记失败、撤单。

## 净值与日期

纳指雷达更新时，从天天基金历史净值接口为每只基金读取并保存最近三条正式单位净值。
保存定投计划只读取缓存，不单独请求净值，缓存不完整则提示纳指雷达数据异常并回滚保存。
每日计划按周一至周五安排；完整基金开放日历尚未接入。
如果申购日期早于最老的缓存净值日且没有已确定的成交净值，不将最老缓存净值冒充成交净值。
15:00 前采用当日或其后首个正式净值；15:00 后采用严格晚于申购日期的首个正式净值。
尚无对应净值时，保持在途金额，份额为空。

## 份额与结转

预计份额 =（扣款金额 - 计划手续费）/ T 日单位净值，暂按两位小数四舍五入。
计划未填手续费时按 0 估算。预计份额可以根据实际确认结果修正。
预计份额在在途状态下不计入已确认持仓市值和收益。
数据更新时补齐预计份额；T 日移出最近三个净值日窗口后，按用户约定将同一条自动记录结转为持仓。
只对自动生成的记录应用自动结转规则，人工在途保持原有处理流程。

## 去重与历史

自动记账标记已处理的日期；编辑计划不重新生成历史扣款，暂停期间不补记。
按计划 ID 与申购日期检查已有记录，避免重复记账。
更早净值快照可能作为既有持仓收益计算依据留存；自动在途规则只读取最新三个净值日。
