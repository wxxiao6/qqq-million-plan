# Nasdaq mark source

- Vector source: https://commons.wikimedia.org/wiki/File:NASDAQ_Logo.svg
- Original vector: https://upload.wikimedia.org/wikipedia/commons/8/87/NASDAQ_Logo.svg
- The source credits Nasdaq and its 2019 trade calendar: https://www.nasdaq.net/PublicPages/assets/MyMID/Trade_Calendar_2019.pdf
- Official-site visual reference: https://www.nasdaq.net/_res/pubimages/NDAQ_LOGO_20191003.png

`nasdaq-mark.svg` contains the three original blue symbol paths from the vector source, with their original proportions and colors. Only the wordmark and unused clipping definitions were removed. The project name remains 百万纳指计划.

Generate browser, Apple touch and PWA icons with `node scripts/generate-pwa-icons.mjs`. The application icons have a solid light background and keep the mark inside the maskable safe circle. The Nasdaq name and mark belong to Nasdaq; including these assets does not indicate sponsorship or affiliation.
