# 百万纳指计划

一个用于查看纳指基金额度、记录持仓和管理定投的工具。

## 纳指雷达

- 查看人民币场外基金、场内 ETF、主动管理基金和美元计价 QDII 份额。
- 查看基金净值、日涨跌、申购状态、购买额度及手续费等信息，并按基金类型和销售渠道筛选。
- 手动更新基金净值与额度，查看不同渠道的购买情况。

## 持仓管理

- 按基金和购买渠道记录、编辑持仓及待确认申购。
- 查看持仓市值、买入成本、持有收益和单日收益。
- 按基金或销售渠道筛选持仓，查看组合汇总及各渠道明细。

## 定投管理

- 按基金和购买渠道创建定投计划，设置每期金额和执行频率。
- 查看计划状态、执行记录和定投日历，支持暂停、恢复及结束计划。
- 按计划自动生成记账记录，并支持根据实际扣款修正记录。

定投功能用于记账，不会在购买渠道发起交易；实际申购、扣款与成交情况以购买渠道为准。

## 添加为手机应用

访问线上 HTTPS 网站，点击右上角手机图标查看安装入口。iPhone / iPad 使用 Safari 的「分享 → 添加到主屏幕」；安卓使用 Chrome / Edge 的「安装应用」或「添加到主屏幕」。安装后以独立窗口启动，全站页面均可访问，首次可能需要重新登录。

查看金融数据和记账需要联网。离线时显示连接提示，不在 Service Worker 中缓存持仓、账号、API 或交易请求，也不离线提交记账。新版本准备好后会提示刷新，由用户保存表单后主动更新。

PWA Service Worker 仅在生产构建启用；本地验证可运行 `DISABLE_JOBS=1 pnpm build`，再 `pnpm start --port 3100`（localhost 支持 Service Worker）。离线资源变更时需同步更新 `public/sw.js` 中的缓存版本。
